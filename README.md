# UNP_PROJECT_MACHINE_LEARNING_WITH_PYTHON_DIGITAL_HABITS_VS_MENTAL_HEALTH_REGRESSION

Digital Habits & Mental Health Analysis | Machine Learning Regression
 
This project was developed in collaboration with UNP Education and focuses on analyzing the impact of digital habits on mental health using machine learning regression techniques in Python. It follows a complete ML pipeline including data preprocessing, exploratory data analysis, model building, and evaluation.
 
Regression algorithms used:
 
* Linear Regression
* Decision Tree Regressor
* Random Forest Regressor
 
Tools & Technologies: Python, Pandas, NumPy, Matplotlib, Seaborn
